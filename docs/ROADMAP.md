# Roadmap

## v0.1.0 — Initial Release

- [x] Rule-based parser for meeting transcripts
- [x] Web UI for transcript input and structured output
- [x] Support for decisions, action items, open questions, and key topics
- [x] Client-side only (no backend required)

## Future

- [ ] Export summaries as PDF or Markdown
- [ ] Speaker detection and attribution
- [ ] Sentiment or urgency scoring for action items
- [ ] Dark mode
- [ ] Persistent history (localStorage)
- [ ] Multi-language support
